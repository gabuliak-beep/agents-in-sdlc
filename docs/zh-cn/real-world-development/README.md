通过真实场景、完整应用和共享待办列表，探索 GitHub Copilot 在软件开发生命周期中的应用。你将迭代式地规划更改、编写代码、测试行为、审查拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为桌游众筹提供服务，并以开发者为主题。团队的待办事项已作为 GitHub issue 创建，等你着手处理。其中包括筛选和分页等功能，也包括无障碍和编码规范等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择适合你的开发环境。每个工作坊都有独立的设置步骤，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。使用 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright MCP、Agent Merge 和实用的斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行代理会话、切换会话模式、协作使用画布，以及管理 GitHub issue 和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub issue 分配给异步代理，引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
